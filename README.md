## เกมนี้เล่นยังไง

เกม idle แปลว่า **คุณสั่งงานแล้วปล่อยให้มันทำ** ไม่ต้องนั่งกดรัว ๆ งานเดินต่อขณะคุณทำอย่างอื่น
และเดินต่อแม้ปิดหน้าจอไปแล้ว (ได้ 30% ของปกติ สูงสุด 8 ชั่วโมง)

### 1. เลือกอาชีพแล้วสั่งงาน

มี 9 สายอาชีพ กดการ์ดงานหนึ่งใบแล้วปล่อยไว้ ยิ่งทำซ้ำยิ่ง **ชำนาญ** ขึ้น ซึ่งทำให้เร็วขึ้นและได้ของดีขึ้น

![หน้าสายอาชีพ](img/02-skill.png)

### 2. ออกล่า

เอาของที่หาได้ไปตีเป็นอาวุธและเกราะ แล้วออกล่ามอนสเตอร์ สัตว์เลี้ยงช่วยรับดาเมจแทนคุณได้
และล่าสายพันธุ์เดิมครบ 1,000 ตัวเมื่อไหร่ **มันจะเริ่มกลัวคุณ** แล้วตีเบาลง

![หน้าต่อสู้](img/03-combat.png)

### 3. ลานหมู่บ้าน — รับงาน และจีบสาว

ชาวบ้านทุกคนมีงานให้ทำ กดดูแล้วเช็คกระเป๋าให้ทันที มีของครบก็ส่งได้เลย ไม่มีก็กด **"ไปหาของ"**
แล้วเลือกได้ว่าจะไปหาจากทางไหน

อีกแท็บคือความสัมพันธ์ ให้ของขวัญเพื่อสนิทขึ้น จนถึงขั้นแต่งงานได้ **แต่ละคนหนุนคนละอย่าง** —
พืชโตเร็วขึ้น ดาเมจมากขึ้น ขายของได้ราคาดีขึ้น เจอของหายากบ่อยขึ้น หรือได้ XP มากขึ้น

![ลานหมู่บ้าน](img/04-village.png)

### 4. ครอบครัว

แต่งงานแล้วมีลูกได้ (โอกาส 3% ต่อวันในเกม) ลูกเริ่มต้นด้วยค่าสถานะครึ่งหนึ่งของคุณตอนที่เขาเกิด
แล้วค่อย ๆ โตขึ้น คุณเลือกได้ว่าจะส่งเขาเรียนอะไร — **ยิ่งเรียนสูงยิ่งแพงและคืนทุนช้า**

![ครอบครัว](img/05-family.png)

### 5. การจุติ — และสิ่งที่รอด

เมื่อแข็งแกร่งพอ คุณเลือก **จุติ** ได้ สเตตัสการต่อสู้จะถูกหารครึ่ง แลกกับบุญที่ติดตัวไปตลอด
สิ่งที่รอดกับไม่รอดถูกออกแบบมาให้เดาได้:

| รอดถาวร | หารครึ่ง | หายไป |
|---|---|---|
| ความสำเร็จและฉายา · รอยล่า · เงินฝาก หุ้น ธุรกิจ อสังหา | สเตตัสการต่อสู้ · ความสัมพันธ์ | ทองในมือ · ลูกและการเรียนของเขา |

ความสัมพันธ์มี **พื้น** กันไม่ให้ตกต่ำกว่าชาติก่อน — จุติหลายรอบเข้า การกลับไปหาคนเดิมยิ่งเร็วขึ้น

## สองภาษา / Two languages

กด ⚙️ แล้วเลือก 🇹🇭 ไทย หรือ 🇬🇧 English

**เนื้อหาแปลครบ 100%** — ไอเทมทั้ง 164 ชิ้น มอนสเตอร์ทุกตัว อาชีพและงานทั้งหมด ความสำเร็จ ชาวบ้าน บริษัท อสังหา
รวมถึงคำโปรยใต้ชื่อสถานที่ **เปลือก UI แปลแล้วเกือบทั้งหมด** — เมนู หัวข้อ การ์ดงาน ปุ่ม แถบสถานะ

ยังเหลือข้อความบางส่วนที่ฝังอยู่ในหน้าย่อย ๆ (ธนาคาร ภาษี กิลด์) ซึ่งทยอยแปลอยู่ —
คำที่ยังไม่ได้แปลจะแสดงเป็นไทยไว้ก่อน ไม่มีทางกลายเป็นช่องว่าง

_Content is fully translated. Most of the interface is too; some deeper panels still show Thai,
and anything untranslated falls back to Thai rather than breaking._

## เซฟอยู่ไหน / Where saves live

เก็บใน **localStorage ของเบราว์เซอร์** แยกตามเว็บไซต์ แปลว่า:

- เซฟอยู่กับเครื่องและเบราว์เซอร์ที่คุณเล่น
- ล้างข้อมูลเว็บไซต์ = เซฟหาย
- ย้ายเซฟได้ด้วยปุ่ม **ส่งออก / นำเข้า** บนหน้าโปรไฟล์ — มันเขียนไฟล์ให้คุณพกไปเครื่องอื่นได้

ไม่มีอะไรถูกส่งออกไปไหนทั้งนั้น ไม่มีบัญชี ไม่มีการเก็บข้อมูล

## เอาไปทำต่อเอง / Make it your own

โหลด [release ล่าสุด](../../releases) แล้วแตกไฟล์ หรือ clone repo นี้

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

เท่านั้นเอง — ไม่ต้อง `npm install` ไม่ต้อง build ไม่ต้องมี Node

### ไฟล์อะไรอยู่ตรงไหน

| ไฟล์ | คืออะไร |
|---|---|
| `data.js` | **ตัวเลขทั้งเกม** — ไอเทม อาชีพ งาน มอนสเตอร์ ราคา ความสำเร็จ อยากปรับสมดุลแก้ที่นี่ |
| `game.js` | กติกาและการวาดหน้าจอ |
| `i18n.js` | พจนานุกรมไทย→อังกฤษ ใช้ข้อความไทยเป็นคีย์ |
| `style.css` | หน้าตาทั้งหมด |
| `art/` | รูปมอนสเตอร์ สัตว์เลี้ยง ตัวละคร |
| `dist/ui.js` | ส่วน React ที่ build แล้ว (source อยู่ใน repo หลัก) |

### ลองแก้อะไรก่อนดี

เปิด `data.js` แล้วลอง:

```js
// ทำให้ตัดไม้เร็วขึ้นสิบเท่า — หา action ที่อยากแก้แล้วลด seconds
{ id: "oak", name: "ต้นโอ๊คเก่าแก่", seconds: 0.15, ... }

// เพิ่มไอเทมใหม่
newthing: { name: "ของใหม่ของฉัน", icon: "🌟", sell: 999 },
```

รีเฟรชหน้าเว็บก็เห็นผลทันที ไม่ต้อง build

> **ระวัง:** `GAME_VERSION` ใน `data.js` เป็นทั้งตัวล้าง cache **และ** กุญแจความเข้ากันของเซฟ
> ถ้าขยับเลขนี้โดยไม่เขียนขั้น `migrate()` ให้ตรงกัน **เซฟทุกอันจะกลายเป็นช่องว่าง**

### แปลเป็นภาษาอื่น

`i18n.js` ใช้ข้อความไทยเป็นคีย์ตรง ๆ เพิ่มภาษาใหม่ก็แค่ทำ object แบบเดียวกัน
คำที่ยังไม่แปลจะแสดงเป็นไทยไว้ก่อน ไม่พัง
